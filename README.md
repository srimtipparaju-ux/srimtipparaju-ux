## 🚀 Featured Projects

### 🤖 OpsMind (formerly PerfAgent) — AI SRE Copilot Platform

An autonomous AI SRE copilot that ingests production diagnostic artifacts (AWR reports, SQL Monitor output, thread/heap dumps, JFR recordings, JMeter results, stack traces, Kubernetes diagnostics), runs **parallel domain-specific LLM analysis across 10 specialized skills**, correlates findings into a unified causal chain, and dispatches severity-ranked output to Slack, Jira, and email — **end-to-end triage in 25–40 seconds at ~$0.10 per incident** (a ~200× time and ~5,000× cost reduction vs. manual triage).

- **Architecture:** 5-agent system (Classifier, Skill Analyzer, Cross-Artifact Correlator, Chat Agent, Reporter) on a 6-step orchestrated pipeline.
- **RAG:** Pinecone + OpenAI `text-embedding-3-small` retrieves runbooks/postmortems before every analysis, with an in-memory cosine-similarity offline fallback.
- **LLMOps:** Prometheus tracks tokens, P50/P90/P99 latency, USD cost, and parse success rate — with a pre-built Grafana dashboard.
- **Tech:** `Node.js` · `TypeScript` · `Anthropic Claude` · `Pinecone` · `OpenAI Embeddings` · `Express` · `Prometheus` · `Grafana` · `Docker` · `AWS ECS`
